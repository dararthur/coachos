## Contrôles exécutés

- `tests/db/privacy.test.ts` : 19/19, dont les 3 nouveaux cas (export photo, export du compte, suppression du compte).

- ESLint sur les fichiers modifiés : 0 erreur. `npm run audit:secrets` : OK.
- **Non exécutés** : tests e2e Playwright, `npm run pilot:preflight` contre la production, toute vérification sur le serveur OVHcloud ou le compte Resend.
